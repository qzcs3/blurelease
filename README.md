# Releases

APK releases live on the **Releases** page. Every release contains a single installable app package plus its version code.

## How it works
- Each release is tagged with a number — the version code (e.g. `20641`). Higher = newer.
- The app checks this page from a "Check for updates" button.
- Download the `.apk` asset and open it on your device to install.
- Install is an in-place update — your app data is kept.
- If updates don't seem to arrive, your OS must allow "install from unknown sources" for this app.

## Naming
| Asset | Meaning |
|---|---|
| `Blury-vxxx.apk` | Latest build, automatically picked up by the app |

## Pages
- **[Releases](../../releases)** — all published builds
- **[Tags](../../tags)** — version history

Nothing else lives in this repo — it exists purely to serve app updates.
